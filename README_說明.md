# 《騎咧走》遊戲：分開版

這是把遊戲單檔拆開後的版本：HTML、CSS、JavaScript、圖片、影片都是獨立的檔案，跟一般網站專案一樣。內容和網站上的遊戲完全相同。

## 檔案結構

```
騎咧走_遊戲分開版/
├─ index.html                 遊戲頁面（畫面結構：標題、平板、對話框、按鈕…）
├─ css/
│   └─ style.css              全部樣式（配色、版面、按鈕、對話氣泡、動畫）
├─ js/
│   ├─ game.js                啟動前的小設定
│   └─ game-2.js              遊戲主程式（劇情、四個關卡、3D 第一關、平板、商店、存檔、音樂音效、無限探索…）
├─ images/
│   ├─ backgrounds/           背景：第一關麵攤、第二關住宅騎樓、載入畫面
│   ├─ characters/            角色：主角、老師、媽媽與寶寶、老闆、客人
│   ├─ logo/                  Logo、開場動畫最後一格
│   ├─ icons/                 徽章、商店物件、名次、裝飾貼紙（SVG，可用 Illustrator 打開）
│   └─ ui/                    便條紙紋理
├─ video/
│   └─ 開場logo動畫.mp4
├─ 啟動遊戲_Windows.bat        Windows 雙擊這個開遊戲
├─ 啟動遊戲_Mac.command        Mac 雙擊這個開遊戲
└─ 騎咧走_單檔版_可直接雙擊.html  全部包在一起的版本，直接雙擊就能玩
```

## 怎麼開遊戲

**分開版不能直接雙擊 `index.html`。** 瀏覽器的安全限制不讓 3D 引擎讀取電腦裡的圖片檔，第一關會出錯。請用下面任一種方法：

1. **雙擊 `啟動遊戲_Windows.bat` 或 `啟動遊戲_Mac.command`**：電腦裡要有 Python，會自動打開瀏覽器。
2. **VS Code**：安裝「Live Server」擴充功能，在 `index.html` 上按右鍵 →「Open with Live Server」。
3. **上傳到 Netlify**：把整個資料夾拖進 Netlify 就能用。

只想玩的話，直接雙擊 `騎咧走_單檔版_可直接雙擊.html` 最方便。

## 想修改的話

| 想改的東西 | 改哪裡 |
|---|---|
| 換角色、背景、Logo | 用同檔名覆蓋 `images/` 裡的圖 |
| 換徽章、商店物件圖示 | 覆蓋 `images/icons/` 裡的 SVG |
| 顏色、字體、按鈕樣式 | `css/style.css` |
| 台詞、任務、關卡、遊戲規則 | `js/game-2.js`（用「搜尋」找台詞文字最快） |
| 英文翻譯 | `js/game-2.js` 裡的 `DICT_EN` |

**其他說明**
- **音樂和音效**：都是程式即時合成的（Web Audio），所以沒有音檔，程式在 `js/game-2.js` 裡。
- **3D 引擎 three.js**：從網路載入，所以第一次開需要連網。
- **存檔**：存在瀏覽器裡（localStorage），換瀏覽器或清除瀏覽資料就會重來。
